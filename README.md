# OceanX Mobile UI Assignment

Mobile Application Developer Internship assignment for OceanX Agency.

## Project Overview
This project recreates the **"My Orders"** Android screen UI provided in the assignment reference using Android Native development.

## Features
- Kotlin + XML
- RecyclerView for order listing
- Bottom Navigation
- Search bar UI
- Filter & Sort buttons
- Order status tabs
- Material click effects
- Responsive design
- Clean and structured code

## Tech Stack
- Kotlin
- XML
- RecyclerView
- ViewBinding
- Material Components

## Project Structure
